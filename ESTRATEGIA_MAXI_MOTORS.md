## 3. TECH STACK RECOMENDADO

| Capa | Tecnología | Razón |
|---|---|---|
| **Framework** | **Astro** (recomendado) o **Next.js** (SSG) | Generación estática = velocidad máxima. Astro pesa 0KB JS por defecto. |
| **CSS** | **Tailwind CSS** + **DaisyUI** | Maquetación rápida, responsive nativo, componente de navbar/cards listos. |
| **Imágenes** | **WebP** + **AVIF** fallback + lazy loading nativo | Carga bajo 2 segundos en 4G. |
| **Mapa** | **Google Maps Embed** (gratuito sin API key para embed simple) | Sin costo, carga bajo demanda. |
| **Formulario** | **Formspree** o **Netlify Forms** | Captura leads sin backend costoso. |
| **Analytics** | **Google Analytics 4** + **Google Search Console** | SEO local + tracking de conversiones. |
| **Hosting** | **Vercel** o **Cloudflare Pages** | CDN global gratuito, builds automáticos desde GitHub. |
| **Dominio** | `.pa` (nic.pa) | SEO local + credibilidad en Panamá. |
| **SEO** | **astro-seo** package + **Schema.org/LocalBusiness** | Meta tags dinámicos, rich snippets en Google. |
| **WhatsApp** | **Widget JS** (personalizado con parámetro `?text=`) | Captura modelo del vehículo: "Hola, quiero info del [TOYOTA HILUX 2022]" |

## 5. RECOMENDACIONES ESTRATÉGICAS

### A. WhatsApp Inteligente
- Botón flotante **siempre visible** en mobile y desktop
- El clic abre `wa.me/507XXXXXXXX?text=Hola%2C%20quiero%20informaci%C3%B3n%20del%20[VEHÍCULO]`
- El nombre del modelo se inserta automáticamente desde la página donde está el usuario
- **Horario:** Indicar "🟢 Disponible ahora" o programar respuesta automática fuera de horario

### B. SEO Local (Panamá)
- **Keywords target:** "vehículos certificados en Panamá", "autos seminuevos garantizados Ciudad de Panamá", "financiamiento de autos en Panamá", "concesionario certificado Panamá", "comprar auto usado con garantía Panamá"
- **Google Business Profile:** Completar con fotos del local, horario, reseñas de clientes
- **Schema LocalBusiness** en el `<head>` con dirección, teléfono, horario
- **Mapa embebido** con la ubicación exacta de Maxi Motors
- **Contenido geolocalizado:** Mencionar distritos y corregimientos (Bella Vista, San Francisco, Bethania, etc.)

### C. Velocidad Móvil (Mobile First)
- **Imágenes:** WebP a 80% calidad, máximo 150KB por foto de vehículo
- **Carga progresiva:** Las imágenes fuera del viewport tienen `loading="lazy"`
- **CSS crítico:** Inline para el Hero Above the Fold
- **JS mínimo:** Astro elimina JS no usado. Si usas Next.js, activa `next/image` y `next/script` con strategy `lazyOnload`
- **Métrica objetivo:** Lighthouse Mobile > 90 (actualmente +70% del tráfico en Panamá es mobile)
- **CDN:** Cloudflare o Vercel Edge Network (latencia mínima en Latinoamérica)

### D. Bonus — Conversión
- **Pop-up de salida:** "¿Te vas tan pronto? Te ofrecemos $500 de descuento adicional si financiás hoy con BAC."
- **Lead magnet:** Guía descargable "7 pasos para comprar tu seminuevo sin estrés en Panamá" a cambio del email
- **Chatbot híbrido:** Responder preguntas frecuentes (precios, documentos, financiamiento) automáticamente antes de escalar a un asesor real
